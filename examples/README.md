# Examples

Each example renders one image to the current directory. They are not part of
the published npm package; they use the workspace build of
`@fazelstudio/mini-canvas`.

```sh
bun install
bun run build   # builds the WASM core + TypeScript wrapper once
cd examples
bun basic-card.mjs
```

| Example | Shows |
| --- | --- |
| `basic-card.mjs` | rounded rectangle, linear gradient, stroke |
| `gradient.mjs` | radial gradient on a transparent background |
| `path-and-transform.mjs` | paths, quadratic curves, save/restore, rotate |
| `text-image.mjs` | fontdue text + cover-clipped JPEG image |

Fixtures (`../fixtures/`) provide the font and photo used by `text-image.mjs`:

- `fixtures/fonts/FiraSans-Regular.ttf` — SIL OFL 1.1 (license in
  `fixtures/fonts/OFL.txt`)
- `fixtures/images/photo.jpg` — generated by `fixtures/images/generate-photo.mjs`
  using mini-canvas itself, so no external image is required

Any TrueType/OpenType font or PNG/JPEG file can be substituted in the
examples.
